# Groundwater Contamination Modeling Across New York State

Numerical modeling project completed for CE 31500 at The City College of New York.

## Overview
Developed a one-dimensional groundwater contaminant transport model using Python and FiPy to compare plume migration across representative soil conditions in Suffolk, Dutchess, and Cattaraugus Counties.

## Tools
- Python
- FiPy
- NumPy
- Matplotlib
- Finite Volume Method

## Project Highlights
- Solved the 1-D advection-dispersion equation
- Simulated contaminant transport over 400 days
- Compared transport behavior across three soil conditions
- Performed mesh and time-step refinement to evaluate numerical error
